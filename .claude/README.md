# Материалы для ИИ-агентов

Папка нужна только Claude Code и совместимым инструментам. На работу приложения
она не влияет — можно спокойно удалить, если не пользуетесь ИИ-помощниками.

## Что здесь

```
.claude/
└── skills/
    ├── ufc-selectors/SKILL.md    Починка парсеров при изменении вёрстки ufc.com
    ├── model-tuning/SKILL.md     Веса, экспертные правила, бэктест и калибровка
    ├── betting-market/SKILL.md   Сквозное добавление нового рынка ставок
    └── odds-provider/SKILL.md    Подключение нового источника коэффициентов
```

Общие правила работы с кодовой базой — в `AGENTS.md` в корне проекта.
Он читается всегда; скилы подключаются по мере необходимости, когда задача
совпадает с описанием в их заголовке.

## Как это работает

Каждый скил — папка с файлом `SKILL.md`. В начале файла YAML-заголовок:

```yaml
---
name: имя-скила
description: Когда его применять — по этому описанию агент решает, открывать ли файл.
---
```

Дальше — пошаговый порядок действий: что проверить, какие файлы править,
чем убедиться, что вышло правильно.

Скилы лежат в репозитории, а значит доступны в любой сессии, открытой в этой папке,
и переезжают вместе с проектом. Это не то же самое, что скилы в аккаунте
Claude — те работают везде, но не знают про конкретно этот проект.

## Как добавить свой

Создайте `.claude/skills/имя/SKILL.md` с таким же заголовком. Описание пишите
через задачи и формулировки, которыми вы сами описываете проблему — по нему
происходит выбор. Хорошее описание перечисляет симптомы («парсер вернул ноль
турниров»), а не только тему («парсинг»).

Держите в скиле процедуру, а не пересказ кода: что открыть, что изменить,
что легко упустить и чем проверить результат.
