## Что происходит

Проект переписывается с нуля по плану из `docs/roadmap-v2.md`.
Первая версия дала 12 дефектов; их разбор и деление на 11 этапов — в том же файле.
Исходные требования к продукту — `docs/requirements.md` (не менять).

Порядок работы, согласованный с ALEX:

1. Один этап за раз.
2. Claude сам исполняет и тестирует код до передачи.
3. На каждый этап пишется ТЗ и **тест-план для ALEX** (образец — `docs/stage-0.md`, раздел 0.7).
4. **Следующий этап не начинается, пока ALEX не скажет.**
