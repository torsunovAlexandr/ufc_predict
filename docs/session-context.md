### Ограничение песочницы Cowork — важно для следующей сессии

Пуш в репозиторий и GitHub API отклоняются прокси песочницы:

```
access denied by the git proxy: torsunovAlexandr/ufc_predict is not in
this session's authorized repository set
```

`git clone` при этом работает: чтение разрешено, запись — нет. Токен здесь ни при
чём. Лечится добавлением репозитория в **источники сессии** в интерфейсе Claude;
как и сетевые настройки, это может подействовать только на новую сессию.

Отдельно: `composer` не может скачивать dist-архивы — `api.github.com/.../zipball`
и `codeload.github.com` отдают 403 от прокси. Установка идёт через `--prefer-source`
(git clone пакетов работает). Пакет `phpstan/phpstan` распространяется **только**
dist-архивом, без git-исходников, поэтому для локальной проверки он был положен
в кэш composer вручную. В GitHub Actions этой проблемы нет.
